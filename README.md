## Contents

### 📁 occluded_dataset
WiderPerson dataset for dense pedestrian detection in the wild. This dataset contains 13,382 images with approximately 400K annotations covering various occlusion scenarios.

**Dataset Details:**
- **Training images:** 8,000
- **Validation images:** 1,000  
- **Testing images:** 4,382
- **Classes:** Pedestrians, Riders, Partially-visible persons, Ignore regions, Crowd

**Source:** Official WiderPerson Dataset  
**Website:** http://www.cbsr.ia.ac.cn/users/sfzhang/WiderPerson/

**Citation:**
```
Zhang, S., Xie, Y., Wan, J., Xia, H., Li, S. Z., & Guo, G. (2020). 
WiderPerson: A Diverse Dataset for Dense Pedestrian Detection in the Wild. 
IEEE Transactions on Multimedia, 22(2), 380–393. 
DOI: 10.1109/TMM.2019.2929005
```

For detailed documentation on the dataset format, annotation structure, and evaluation procedures, see [occluded_dataset/README.md](occluded_dataset/README.md).
